# Adventure Journal (Java Swing, OOP)

## Compile & run (JDK 11+), from this folder
    mkdir out
    javac -d out src/*.java        # Windows: javac -d out src\*.java
    java -cp out Main

Run from the project root so that `images/` is found.

## Images (optional)
Put PNG files in `images/`: Warrior.png, Mage.png, Goblin.png, Orc.png, Boss.png.
Missing files are drawn as a placeholder box with the name.
